# AI Meeting Assistant

AI-powered meeting assistant that processes YouTube videos and audio files to generate transcripts, summaries, action items, decisions, and contextual chat over meeting content.

## Features
- YouTube URL and audio/video file input
- English transcription with local Whisper
- Hindi and Hinglish transcription with Sarvam AI
- Meeting summarization in bullet points
- Action item extraction with owner and deadline
- Key decision extraction
- Open questions and follow-up extraction
- RAG-based chat with ChromaDB
- PDF and TXT export

## Tech Stack
Python, Streamlit, LangChain, ChromaDB, Whisper, Mistral AI, Sarvam AI, Docker
